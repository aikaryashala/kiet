KIET Bootcamp 3 21st & 22nd Sep 2026

Python backend with Bottle + SQLite. You arrive knowing C; you leave with a program that answers HTTP requests with JSON from a database, and a web page that uses it. Nine stages on Day 1, presentations and Omarchy on Day 2. Day 1 is completely offline, on purpose: every resource needed to follow and run the stages is already on your machine.
