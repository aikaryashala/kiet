Get your laptop ready

The bootcamp runs on Linux. Bring a laptop running Ubuntu 24.04 or Omarchy; if yours runs Windows, put Ubuntu on it with the steps below.

Already on Ubuntu 24.04 or Omarchy?

Nothing to do on this page. Go straight to Make your system ready for offline bootcamp and run the one setup line.

Want to install Ubuntu 24.04 on Windows in a VM?

Windows can run Ubuntu inside it through WSL, the Windows Subsystem for Linux. Three commands, one restart. Every command below runs in PowerShell opened as Administrator: press the Windows key, type PowerShell, right-click Windows PowerShell and choose Run as administrator. Say Yes when Windows asks for permission.

  1. Turn on WSL. This downloads the Linux layer; it can take a few minutes.

    PowerShell — as Administrator
    PS> wsl --install

  2. Restart Windows so the new layer starts. Save your work first — this restarts at once, with no countdown.

    PowerShell — as Administrator
    PS> shutdown /r /t 0

  3. After the restart, open PowerShell as Administrator again and install Ubuntu 24.04. At the end it asks you to choose a Linux username and password; remember them, the setup step asks for that password.

    PowerShell — as Administrator
    PS> wsl --install -d Ubuntu-24.04

From now on, Ubuntu 24.04 appears in the Start menu. Open it: that is your Linux terminal, and everything on the setup page runs inside it.

Forgot your Ubuntu password?

This is the Linux password you chose in step 3, the one sudo asks for. It is not your Windows password. On WSL there is no recovery menu to boot into: Windows can start Ubuntu as root directly, and root may set any user's password.

  1. Open PowerShell as Administrator and check the exact name of your Ubuntu. The next command needs it spelled the same way.

    PowerShell — as Administrator
    PS> wsl -l -v  NAME              STATE           VERSION* Ubuntu-24.04      Stopped         2

  2. Start that Ubuntu as root. The prompt ends in # instead of $: you are root. A warning about motd may appear; ignore it.

    PowerShell — as Administrator
    PS> wsl -d Ubuntu-24.04 -u rootroot@LAPTOP:/mnt/c/Windows/system32#

  3. Find your username: it is the folder in /home. Then set a new password for it. Nothing shows while you type the password; that is normal.

    Ubuntu — as root
    # ls /home/kiet# passwd kietNew password:Retype new password:passwd: password updated successfully# exit

    Use your own name from ls /home/ in place of kiet.

  4. Open Ubuntu 24.04 from the Start menu as usual and confirm the new password works with sudo.

    Ubuntu — you, as usual
    $ whoamikiet$ sudo whoami[sudo] password for kiet:root

    If the last line says root, the new password is in place and sudo works. Carry on with the setup page.
