Make your system ready for offline bootcamp

One command, with internet, before the bootcamp. After it, nothing needs the network.

curl -sSL https://aikaryashala.com/kiet/bootcamp-03/scripts/setup.sh | bash

What you need

A laptop running Ubuntu 24.04 (a VM is fine) or Omarchy. Internet, once, for the step below. After that the bootcamp needs no network. If you did the earlier bootcamps, you already have most of it; run the command anyway — it is safe to repeat.

The script installs three small tools — git, curl, sqlite3 — checks that python3 is 3.12 or newer, and clones the bootcamp repository to ~/kiet-bootcamp-3. Nothing else is installed: no pip, no virtual environment. Bottle, the one library used, is a single file already inside the repository.

Open the bootcamp guide now

Everything the bootcamp uses is now on your disk. Start the guide and open it — the same pages as https://aikaryashala.com/kiet-bootcamp-3/, served from your own machine:

terminal
$ cd ~/kiet-bootcamp-3/docs && python3 -m http.server 8000Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...

Open http://localhost:8000. Leave that terminal running; Ctrl+C stops it. Read Stage 0 ahead of time if you can — it is the Python you will need on Day 1.

  3. Open http://localhost:8000 and begin at Stage 0. You will open two or three more terminals as the stages ask; each page says which terminal a command runs in.

If something fails

curl: command not found
Install it first: sudo apt install curl (Ubuntu) or sudo pacman -S curl (Arch), then run the setup line.
python3 is 3.10 (or lower)
You are on an older Ubuntu, such as 22.04. The script installs python3.12 for you from the deadsnakes PPA and makes python3 mean 3.12 in your own terminal, leaving the system's Python alone. When it finishes, close the terminal, open a new one, and run python3 --version: it must say 3.12. If the PPA cannot be added on your network, install python3.12 by hand and re-run the script.
git clone failed
No internet, or GitHub blocked on the network you are on. Try another connection and re-run.
git pull failed
You edited files inside ~/kiet-bootcamp-3 after an earlier run. Either cd ~/kiet-bootcamp-3 && git stash or delete the folder, then re-run.
Windows
The bootcamp targets Linux. Set up the Ubuntu VM from aikaryashala.com/system_setup first, then run the setup line inside it.
